# TruthGuard — Streamlit Fake News Detection

This is a Streamlit frontend for the ML workflow in your original Colab notebook. It keeps the same preprocessing function and four classifiers:
- Logistic Regression
- Decision Tree
- Gradient Boosting
- Random Forest

## Project layout
```
TruthGuard_Streamlit/
├── app.py
├── model.py
├── train_and_save.py
├── requirements.txt
├── data/
│   ├── Fake.csv
│   └── True (1).csv
└── models/             # generated by training script
```

## Setup on Windows / VS Code
1. Install Python 3.10+ and VS Code.
2. Open this folder in VS Code.
3. Place the dataset CSVs in `data/` (do not rename unless you also update `train_and_save.py`).
4. Open Terminal in VS Code and run:
   ```
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   python train_and_save.py
   streamlit run app.py
   ```
5. Streamlit opens the app in your browser.

## Notes
- The model artifacts are generated locally from the provided datasets. They are not included in this starter package.
- Predictions are pattern-based ML outputs and are not live fact-checks.
- The app shows model predictions and a simple majority vote. It does not claim calibrated confidence.
