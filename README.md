## 📌 About the Project

**TruthGuard** is a Machine Learning-based web application developed to detect fake news and distinguish between real and fake news articles using text classification techniques.

With the rapid spread of misinformation across digital platforms, identifying the credibility of news content has become increasingly important. TruthGuard analyzes the textual content of news and uses a trained machine learning model to predict its classification, helping users become more aware of potentially misleading information.

The application combines Machine Learning, Natural Language Processing (NLP), and an interactive web interface to provide a simple and accessible news classification experience.

## 🎯 Objectives

- Detect and classify news articles as Real or Fake.
- Apply Machine Learning and NLP techniques to textual data.
- Make news classification accessible through a user-friendly web application.
- Promote awareness about misinformation and digital media literacy.

## ✨ Features

- 📰 **News Classification:** Predicts whether the submitted news content is Real or Fake.
- 🤖 **Machine Learning Based:** Uses a trained ML model for automated classification.
- 📝 **Text Analysis:** Processes news content for prediction.
- ⚡ **Interactive Interface:** Simple and user-friendly experience.
- 📊 **Instant Prediction:** Displays the classification result after submitting news.
- 🌐 **Web-Based Application:** Easy to access and use through the application interface.

## ⚙️ How It Works

1. The user enters or pastes news content into the application.
2. The text is processed using the preprocessing and vectorization techniques used during model training.
3. The processed text is passed to the trained Machine Learning model.
4. The model analyzes the input and generates a prediction.
5. The application displays the result as **Real News** or **Fake News**.

## 🚀 Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/TruthGuard-Fake-News-Detection.git
```

### 2. Navigate to the project directory

```bash
cd TruthGuard-Fake-News-Detection
```

### 3. Install the required dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
streamlit run app.py
```

The application will open in your browser.
